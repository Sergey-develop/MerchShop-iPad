# MAGNIT TECH — MERCH SHOP

Интерактивная игра для планшета. Текущая клиентская сборка работает **только в демонстрационном режиме**, хранит данные в браузере и не проверяет подлинность физических токенов. Начальный склад содержит 775 единиц по 16 позициям. Остатки общие для обоих дней, начальный вес каждой позиции — 1. При выигрыше одна единица резервируется, при подтверждении выдачи переходит из резерва в выданные. Панель настроек демо открыта локально и не является защищённой административной панелью. Не используйте эту сборку для реальной выдачи.

## Запуск

Требуется Node.js 22 и npm. В папке проекта:

```powershell
npm ci
npm run dev
```

Откройте адрес, указанный Vite (обычно http://127.0.0.1:5173). Завершение — Ctrl+C. Проверки: `npm test` и `npm run build`; `npm run preview` показывает собранную версию. Для доступа с другого устройства потребуется изменить настройки хоста Vite и учесть требования безопасности сети.

## Как работает демо

Игра проходит через заставку, экран Telegram, инструкцию, ввод, розыгрыш и результат. По умолчанию QR-код ведёт на https://t.me/magnittech. Для другого канала укажите HTTPS-ссылку в настройках. Чтобы открыть настройки, пять раз нажмите на левый нижний угол с паузами короче 2,5 секунды. Вернуться можно тем же жестом или кнопкой «В игру». Подписка подтверждается только нажатием кнопки. На экране «Настройки» можно изменить названия, изображения (локальные файлы до 600 КБ), активность, веса, остатки, дату и активный день, диапазон токенов, а также подтвердить выдачу. Изображения и все данные хранятся в localStorage этого браузера. Очистка данных браузера удалит их. Фактические токены не проверяются. Розыгрыш, выдача и сохранение настроек синхронизируются между вкладками через Web Locks или транзакцию IndexedDB; несколько устройств не синхронизированы.

Ключ запроса хранится в sessionStorage до нажатия «Отлично!». Обновление вкладки восстанавливает сохранённый результат без повторного розыгрыша. Нажатие «Отлично!» завершает сессию. Код выдачи — лишь идентификатор демо-выигрыша, не доказательство подлинности токенов.

## Сервер и дальнейшее подключение

`supabase/` содержит подготовительные SQL-миграцию и Edge Function, а также [инструкцию по подключению](supabase/README.md). Сервер по умолчанию не проводит розыгрыш, пока не настроены правила. **Клиент к серверному API пока не подключён**; защищённый вход и административный интерфейс для сервера, защищённая загрузка изображений, интеграционное тестирование на целевой базе и согласованные правила токенов необходимо реализовать и проверить перед production. Гарантии атомарности локального демо не распространяются на устройства. Уникальный код не проверяет подлинность токенов.

Для запуска мероприятия необходимо получить реальные даты, ссылку Telegram, допустимые значения и правила проверки комбинаций, решение о подтверждении выдачи и правила отмены/срока резерва. Нужны также развёрнутый Supabase, права администраторов и проверка параллельных запросов к реальной базе.
